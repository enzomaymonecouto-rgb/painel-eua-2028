# Painel — Projeto EUA 2028

Site estático do painel de acompanhamento de programas de PhD e da trilha paralela de MBA (intake Fall 2028).

- **[Central do PhD](https://enzomaymonecouto-rgb.github.io/painel-eua-2028/)** — programas, pipeline, probabilidades, prazos e diário de avanços.
- **[Painel clássico](https://enzomaymonecouto-rgb.github.io/painel-eua-2028/painel_classico.html)** — visualização original (lista base + cenário com benefícios).
- **[Central do MBA](https://enzomaymonecouto-rgb.github.io/painel-eua-2028/painel_mba.html)** — trilha de MBA STEM com marketing: cenários de financiamento, dívida e teto, visto J-1, teste de inglês, custo jurídico e rota de permanência.

O progresso registrado (status, checklists, diário) fica salvo no navegador de quem usa (localStorage) — use Exportar/Importar para backup.

Este site é gerado a partir do repositório privado do projeto; os painéis aqui são cópias. Fonte dos stipends: pesquisa de julho/2026 em fontes oficiais.
